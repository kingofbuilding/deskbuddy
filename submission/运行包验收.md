# Windows 运行包验收

版本：DeskBuddy 1.3.0，Windows x64，Electron 40.10.2。

运行包由已安装的 Electron 运行时和当前应用源码组装，采用 Electron 官方文档提供的 `resources/app` 分发目录结构。双击可执行文件时直接载入应用，无需安装 Node.js、下载 npm 依赖或配置 API Key。

分发结构依据：[Electron Application Packaging](https://www.electronjs.org/docs/latest/tutorial/application-distribution)。

## 本机实际结果

- 普通启动：当前工具环境下进程立即退出，退出码为 -2147483645。
- 兼容启动：使用 `--no-sandbox --disable-gpu`，退出码 0，43 项应用自检全部通过。
- 自检覆盖：窗口创建、透明背景、角色素材加载、任务添加与落盘、专注计时、面板同步、砍刀与裂屏播放和退场、覆盖层穿透及免打扰等。
- 包内提供 `兼容启动.cmd`，仅向本次进程传递兼容参数，不修改系统设置。
- 本次自检使用独立临时数据目录，运行包和源码包不包含个人任务、设置、API Key、缓存或测试会话数据。
- 完整源码此前通过 134 个自动化用例、43 项应用检查和 7 条端到端流程，见源码中的 `docs/acceptance-report.md`。

本机自检验证了上述环境与参数下的行为，尚未完成另一台干净 Windows 电脑的普通启动验证。
